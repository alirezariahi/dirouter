# Changelog

Per-package entries are in each package's `CHANGELOG.md`, generated by Changesets
([docs/release.md](docs/release.md)).

## 1.0.0 (2026-11-23)

The first stable release. Upgrading from 0.x: [docs/upgrade-v1.md](docs/upgrade-v1.md).

- **Gateway (sprints 1–2):** OpenAI, Anthropic, Responses and Gemini APIs on one endpoint; routing
  strategies, fallback, retries, hedging, circuit breakers shared across replicas, rate limits,
  budgets, exact and semantic caching, guardrails, distributed tracing, zero-downtime drains.
- **Agents and media (sprint 3):** MCP gateway and admin MCP server, A2A, auto routing, coding
  agent profiles, images, speech and transcription, provider plugins.
- **Billing (sprint 3):** prepaid wallets on a double-entry ledger, online top-ups, gift codes, sale
  prices and plans, invoices, a self-service portal.
- **Enterprise (sprints 2–3):** OIDC and SAML sign-in, SCIM provisioning, MFA and passkeys, custom
  roles, audit log, four-eyes approval for sensitive changes.
- **Operations (sprint 3):** signed images with SBOMs and CI vulnerability gates, threat model,
  SSRF protection for tenant URLs, HA compose, Helm chart, documentation site, v1 benchmark and
  ADR-0007.

## MVP (2026-11-11, commit 1207b66, unversioned)

Gateway with OpenAI- and Anthropic-compatible APIs, routing and fallback, virtual keys, the
dashboard, the usage pipeline and docker compose deployment.
