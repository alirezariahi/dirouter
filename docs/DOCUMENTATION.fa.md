# راهنمای مستندات محلی

- [Runbook عملیاتی](runbook.fa.md) — علائم، تشخیص، اقدام و بررسی برای حادثه‌های سرویس
- [راهنمای مشارکت](../CONTRIBUTING.fa.md) — [نسخهٔ انگلیسی](../CONTRIBUTING.fa.md)
