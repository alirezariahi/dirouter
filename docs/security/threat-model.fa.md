# مدل تهدید

[English](threat-model.md)

دامنه: یک استقرار DiRouter مطابق `compose.yaml`، یعنی Traefik، gateway، control-api، worker، داشبورد، پورتال، Postgres و Valkey. اپراتور (سازمان پلتفرم) آن را اجرا می‌کند و ممکن است دسترسی را به سازمان‌های مشتری بفروشد. روش: STRIDE برای هر مرز اعتماد. آخرین بازبینی برای نسخهٔ v1.0 (اسپرینت ۳) انجام شده است.

## دارایی‌ها

| دارایی                   | کجا                                                                                 | اهمیت                                  |
| ------------------------ | ----------------------------------------------------------------------------------- | -------------------------------------- |
| اعتبارنامه‌های provider  | Postgres، رمز‌شده با `MASTER_KEY` (AES-256-GCM با نسخه‌بندی کلید)                   | خرج‌کردن نزد provider و دسترسی به داده |
| کلیدهای مجازی            | hash با pepper (`KEY_PEPPER`) در Postgres و snapshot؛ فقط یک بار نمایش داده می‌شوند | خرج‌کردن از بودجه و کیف پول سازمان     |
| prompt و پاسخ‌ها         | در حال انتقال؛ بدنهٔ درخواست ذخیره نمی‌شود مگر لاگ فعال باشد                        | دادهٔ مشتری                            |
| موجودی کیف پول و دفتر کل | Postgres (فقط-افزودنی و جمع صفر با trigger) و holdهای Valkey                        | پول                                    |
| نشست‌ها                  | access token کوتاه‌عمر JWT و refresh token چرخشی (hash‌شده)                         | تصاحب حساب                             |
| snapshot پیکربندی        | Valkey و پوشهٔ دادهٔ گیت‌وی؛ فقط رازهای رمز‌شده و hash دارد                         | درستی مسیریابی                         |

## مرزهای اعتماد

1. **اینترنت ← Traefik ← گیت‌وی** (`api.`): دارندگان کلید مجازی، که ممکن است مستأجران متخاصم باشند.
2. **اینترنت ← Traefik ← control-api** (`admin.`، `portal.`، داشبورد): کاربران سازمان‌ها و نقش‌های مختلف.
3. **گیت‌وی ← providerها**: APIهای شخص ثالث و هر چیزی که مستأجر به‌عنوان provider تنظیم کند.
4. **سرویس‌های هویت ← control-api**: assertionهای OIDC و SAML و همگام‌سازی SCIM.
5. **شبکهٔ داخلی**: gateway با Valkey، و control-api با Postgres و Valkey، و worker. گیت‌وی به Postgres دسترسی ندارد (ADR-006).
6. **ساخت و انتشار**: وابستگی‌ها، ایمیج‌های پایه، CI و رجیستری ایمیج.
7. **افزونه‌های اپراتور**: افزونه‌های provider.

## خارج از دامنه

امنیت فیزیکی میزبان‌ها، حساب ابری اپراتور و امنیت خود providerها.

## بازبینی

هر وقت مرز تازه‌ای اضافه شد این مدل را دوباره بررسی کنید: پروتکل ورودی جدید، نوع تازه‌ای از URL یا کدی که مستأجر می‌دهد، یا جای جدیدی برای نگهداری رازها.
